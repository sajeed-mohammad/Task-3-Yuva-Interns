
# Task 3 - Advanced Data Analysis and Visualization

## Project Title

Logistics Delivery Delay Exploratory Data Analysis

## Objective

The objective of Task 3 is to analyse the cleaned logistics dataset and identify important patterns, trends and relationships associated with delivery delays.

## Analysis Performed

The following analyses are performed:

1. Descriptive statistics
2. Delivery delay distribution
3. Delay analysis by transportation mode
4. Delay analysis by traffic level
5. Delay analysis by weather condition
6. Delay analysis by delivery priority
7. Distance and delivery delay analysis
8. Warehouse processing time analysis
9. Correlation analysis

## Key Variables

Important variables analysed include:

- Delivery Distance
- Transportation Mode
- Package Weight
- Delivery Priority
- Weather Condition
- Traffic Level
- Warehouse Processing Time
- Planned Delivery Time
- Delivery Delay

## Visualizations

The project can include the following visualizations:

### 1. Delivery Delay Distribution

Shows the number of delayed and on-time deliveries.

### 2. Delay by Transportation Mode

Compares delivery delays across different transportation methods.

### 3. Delay by Traffic Level

Shows how traffic conditions affect delivery performance.

### 4. Delay by Weather Condition

Analyses the relationship between weather conditions and delivery delays.

### 5. Delivery Distance Analysis

Examines whether longer delivery distances are associated with higher delay risk.

### 6. Warehouse Processing Time

Analyses whether longer warehouse processing times contribute to delays.

## Insights

The analysis is used to identify:

- Major contributors to delivery delays
- High-risk operating conditions
- Transportation-related patterns
- Traffic-related patterns
- Weather-related patterns
- Warehouse bottlenecks

## Business Value

The insights from Task 3 help logistics managers:

- Improve route planning
- Allocate resources efficiently
- Identify operational bottlenecks
- Improve delivery scheduling
- Reduce delay rates
